# Agent guidance

This repository is a small public Python project. Keep all source, examples,
tests, commit messages, and review material suitable for a public audience.

- Work on a topic branch and use a pull request for changes to `main`.
- Do not add credentials, private infrastructure details, private history, or
  generated runtime data.
- Keep the implementation dependency-free and deterministic.
- Run `python3 -m unittest discover -s tests -v` and `python3 tools/validate.py`
  before requesting review.
- Do not weaken repository rules, CODEOWNERS, tests, or validation without
  Louis's explicit approval.
- Publishing, repository administration, and bypassing a protection remain
  separate human decisions.
